# 🚗 Car Price Prediction

A data analytics and machine learning project for analyzing automobile prices and predicting car prices using Python, Pandas, SQLite, Linear Regression, and Streamlit.

## 📌 Project Overview

This project analyzes automobile data and provides an interactive Streamlit dashboard.

The project includes:

- Automobile data cleaning and preprocessing
- Data analysis using Pandas
- SQLite database for storing cleaned data
- Automobile filtering by brand and production year
- Average price analysis by brand
- Car price prediction using Linear Regression
- Interactive Streamlit dashboard

## 🛠️ Technologies

- Python
- Pandas
- SQLite
- Scikit-learn
- Linear Regression
- Plotly
- Streamlit
- Jupyter Notebook

## 📊 Features

### 1. Filters

Users can filter automobiles by:

- Brand
- Production year

### 2. Automobile Table

The dashboard displays automobiles matching the selected filters.

### 3. Price Analysis

A chart shows the average automobile price by brand.

### 4. Price Prediction

Users can enter:

- Production year
- Engine size
- Mileage

The Linear Regression model then predicts the estimated automobile price.
